เพิ่มเติม: ต้นทุนต่อชิ้น ราคาขายจำลอง งบเริ่มต้น แผนรายได้รายเดือน และจุดคุ้มทุนโดยประมาณ

หมายเหตุ: ต้นทุน ราคา ยอดขาย และเป้าหมายผลกระทบเป็นตัวเลขสมมติสำหรับใช้ในการเรียน ไม่ใช่ข้อมูลธุรกิจจริง

วิธีอัปโหลด GitHub Pages:
1. แตกไฟล์ ZIP นี้
2. เปิด repository ของเว็บไซต์บน GitHub
3. เลือก Add file > Upload files
4. อัปโหลด index.html และโฟลเดอร์ images ทั้งโฟลเดอร์ที่ระดับหลักของ repository
5. กด Commit changes
6. ไปที่ Settings > Pages
7. เลือก Source: Deploy from a branch, Branch: main, Folder: /(root) แล้ว Save
8. รอ GitHub Pages เผยแพร่เว็บไซต์
